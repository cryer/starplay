# StarPlay

轻量 Rust 终端音乐播放器，面向 Windows Terminal / CMD。默认扫描当前目录，直接播放本地音乐；不上传音频、不修改音乐文件。

## 特性

- 支持 MP3、WAV、FLAC、OGG/Vorbis，扩展名不区分大小写
- 多文件/目录输入、可选递归扫描、路径去重；支持导入/导出 M3U/M3U8 歌单
- 真实音频驱动的彩色频谱与节拍脉冲特效（约 30 帧/秒），不是随机动画
- 同步歌词（`.lrc`）、搜索筛选、随机播放、待播队列
- 逐行差分绘制，空闲时自动降低刷新率；独立播放线程，界面卡顿不影响切歌
- 本地配置文件保存音量、循环和特效模式；`--no-config` 可完全禁用
- 中文文件名按显示宽度裁剪，兼容窄窗口

## 构建与安装

需要 Rust 工具链；Windows MSVC 工具链还需要 Visual Studio C++ 构建工具。

```powershell
git clone <仓库地址>
cd starplay
cargo build --release --locked
```

生成的程序为 `target\release\starplay.exe`。也可以直接安装到 Cargo 目录：

```powershell
cargo install --path . --locked
```

## 快速开始

在音乐目录中启动，或显式传入文件和目录：

```powershell
starplay                          # 播放当前目录
starplay "song.mp3"               # 播放指定文件
starplay --recursive --volume 40 "D:\Music"
starplay "a.mp3" "b.mp3" "我的歌单.m3u8"
```

启动后自动播放第一首可解码的歌曲。需要可用的默认音频输出设备及交互式终端。首次启动音量 50%、顺序播放，之后从启动目录的 `.starplay.conf` 恢复设置；`--volume` 优先于已保存音量。

## 快捷键

| 按键 | 操作 |
| --- | --- |
| ↑ / ↓、J / K | 选择歌曲 |
| Enter | 从头播放选中歌曲 |
| Space | 暂停/继续；播放结束后播放选中歌曲 |
| N / P | 下一首 / 上一首，手动切歌在首尾循环 |
| ← / → | 后退 / 前进 5 秒（取决于解码器是否支持定位） |
| + / - | 音量增减 5%，范围 0–100% |
| R | 循环模式：关闭 → 全部 → 单曲 |
| V | 音乐特效：频谱 → 脉冲 → 关闭 |
| / | 搜索曲名、歌手、专辑；Enter 确认，Esc 清空并退出 |
| S | 开关随机播放 |
| A | 将选中歌曲加入待播队列，可重复加入 |
| Tab | 切换曲库 / 待播队列 |
| Delete / C | 删除选中队列项 / 清空待播队列 |
| L | 显示或隐藏同步歌词 |
| W | 将当前搜索结果或队列导出为 `starplay-playlist.m3u8` |
| Home / End | 选择第一首 / 最后一首 |
| Q / Esc / Ctrl+C | 退出 |

长按方向键、J/K、音量键可连续操作；暂停、切歌等一次性操作不响应按键重复。某些 Unix 终端不提供按键 Release/Repeat 事件，无法区分长按与再次敲击。

## 搜索、随机播放与歌单

按 `/` 实时筛选曲名、歌手和专辑（忽略大小写，支持中文子串）；筛选不改变曲库或自动切歌顺序。

按 A 将选中项追加到待播队列，Tab 查看队列，Delete 删除，C 清空。N 或当前歌曲结束时优先消费队列，即使处于单曲循环；队列允许重复条目，仅在当前会话有效。

S 开启随机播放后，一轮内不重复自动选曲；循环关闭时一轮结束停止，全部循环时重新打乱。P 按实际播放历史回退。

直接传入 UTF-8 `.m3u` / `.m3u8` 歌单即可导入；相对路径以歌单所在目录为基准，支持 BOM、注释和嵌套本地歌单。网络 URL、循环引用、超限和无效条目会报错；单个歌单最大 1 MiB，展开最多 10000 项、32 层。

W 导出当前视图（曲库视图保存搜索结果，队列视图保存待播顺序）到启动目录下的 `starplay-playlist.m3u8`；已有同名文件会提示错误并保留。

同目录、同文件名的 UTF-8 `.lrc` 用于同步歌词，例如 `歌曲.mp3` 对应 `歌曲.lrc`。L 开关显示，歌词随暂停、定位和切歌更新。

## 配置文件

配置文件位于**启动时的工作目录**，正常退出后写入 `.starplay.conf`：

```ini
version=1
volume=50
repeat=off
visual=spectrum
```

- `volume`：0–100；`repeat`：`off` / `all` / `one`；`visual`：`spectrum` / `pulse` / `off`。
- 支持空行和 `#` 注释；`--volume` 覆盖已保存音量，`--no-config` 不读取、不创建也不修改配置。
- `--list`、`--check`、`--help`、`--version` 不访问配置；启动失败不创建配置。
- 非法、超大、未知版本或符号链接配置会显示警告并使用默认设置，不覆盖原文件。
- 配置通过临时文件原子替换写入；只在正常退出时保存，强制终止不保证保存。

## 音乐动态特效

默认显示 24 段彩色频谱，带平滑起落和峰值拖尾；按 V 切换为节拍脉冲、关闭。特效使用实际解码样本，采用 ASCII 图形字符绘制，兼容 CMD；推荐终端至少 80×24。

- **SPECTRUM**：加窗 FFT 与对数频带，范围 40 Hz – 16 kHz；颜色由底部深蓝过渡到顶部洋红和黄色。
- **PULSE**：基于 RMS 能量突增触发向外扩散的光环，结合自适应阈值与噪声门限；这是节奏感可视化，不是精确 BPM 检测。

分析取第一个声道的最近 2048 点窗口，运行在界面线程；音频线程仅发布固定大小快照，不改变播放样本。关闭特效或窗口过小时停止采样分析并降低刷新率；特效随音量变化，暂停、静音及播放结束后平滑衰减。终端高度不足 14 行时自动隐藏特效。

## 命令行模式

```powershell
starplay --list                          # 只列出歌曲，无需终端或声卡
starplay --check                         # 完整消费每首歌的解码输出，无需声卡
starplay --list --recursive "D:\Music"   # 递归列出指定目录
starplay --list -- "-song.mp3"           # 文件名以短横线开头时用 -- 分隔
starplay --help
```

`--list`、`--check`、`--help`、`--version` 互斥。无匹配音乐、路径无效、参数错误或解码失败时返回非零退出码；`--check` 遇到失败仍继续检查剩余歌曲。

## 已知限制

- 切歌需要初始化解码器，不是无缝播放；退出会等待已接受的操作完成。
- `--check` 证明解码器能够产生音频样本，不是严格的文件完整性校验。
- 未知或零总时长显示 `--:--`，不伪造进度；不支持定位的格式会显示错误。
- 标签缺失或无法读取时使用文件名；OGG 容器仅支持 Vorbis。
- 控制台最小建议大小为 32×10；强制终止进程无法保证恢复终端。

## 开发

```powershell
cargo fmt --check
cargo test --locked
cargo clippy --locked --all-targets -- -D warnings
cargo build --release --locked
```

测试覆盖参数解析、排序/递归/去重、中文路径、循环边界、显示宽度、WAV 解码、损坏文件、错误退出码、配置往返、特效分析（FFT 频率定位、脉冲触发与衰减、音量联动）以及完整布局与差分绘制。交互逻辑使用模拟后端和内存终端输出验证，不依赖声卡；依赖缓存后可加 `--offline` 运行。

## 代码结构

- `src/main.rs`：入口、模式分发与退出码
- `src/cli.rs`：参数解析
- `src/library.rs`：曲库扫描及歌单展开
- `src/playlist.rs`：UTF-8 M3U 导入和导出
- `src/browser.rs`：搜索过滤及曲目索引
- `src/media.rs`：本地标签与同步歌词解析
- `src/player.rs`：解码、播放、音量、定位和循环
- `src/playback.rs`：独立播放线程、命令队列、状态快照
- `src/config.rs`：版本化本地配置、校验和安全替换
- `src/input.rs`：键盘映射、长按保护和平台输入策略
- `src/screen.rs`：行缓冲、显示宽度裁剪和差分输出
- `src/audio_visual.rs`：音频采样包装器，有界快照与非阻塞发布
- `src/visualizer.rs`：FFT 频谱、峰值拖尾、能量脉冲与动画衰减
- `src/ui.rs`：终端绘制、输入处理和终端恢复
- `tests/cli.rs`：命令行端到端测试

`Cargo.lock` 固定依赖版本，随源码一起发布。
